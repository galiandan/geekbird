# 极客鸟｜文字与排版

## 核心表达

让设备多用一天，让热爱多走一程。

从设备背后的人出发，用具体的日常解释修复的意义。保留首页与服务页已经确立的主标题，第三页用于免责声明；正文少讲抽象的未来，多讲论文、作品、开机与使用中真实遇到的问题。语气平等、耐心，不催促、不夸大。

## 三页文案

### 首页

**旧物新生 / 热爱不止。**

有些陪伴，值得更久一点。我们用技术，让熟悉的设备继续陪你向前。

**修复一台电脑。接续一段日常。**

极客鸟，是一群愿意为电脑问题多花一点时间的志愿者。

电脑里装着的，可能是还没写完的论文、做到一半的作品，或一个刚刚开始的计划。一次故障，不该轻易打断这些日常。

所以，我们认真听，也耐心修。把问题弄明白，让你用得更安心。

**那些小小的不顺，我们一起理顺。**

系统与软件 / 硬件与散热 / 网络与外设。

页尾：**别急着告别。再给它一次机会。**

### 服务页

**技术无界 / 善意有光。**

你不必先懂电脑，才能寻求帮助。从一个说不清的小问题开始，我们陪你找原因。

**不用懂术语。说说哪里不对劲。**

开不了机、总是卡顿，或只是有点不对劲。你说现象，我们一起找线索。

| 服务 | 说明 |
| --- | --- |
| 系统故障 / 软件问题 | 卡顿、蓝屏、软件打不开，一起找出打断日常的原因。 |
| 硬件检测 / 故障排查 | 开不了机、频繁重启或出现异响，从检测开始定位问题。 |
| 系统安装 / 数据迁移 | 先确认资料与备份，再协助安装系统、迁移常用文件。 |
| 清灰维护 / 散热优化 | 检查积灰、温度与风扇状态，让散热回到应有的节奏。 |
| 网络与外设问题 | 连不上网、认不到设备，从连接、驱动和设置逐项排查。 |
| 其他电脑相关问题 | 说不清问题也没关系。告诉我们遇到了什么，一起看看。 |

原则仍为“能修，不换。能教，不藏。能延续，就不浪费。”，说明强调先沟通方案、把方法讲明白、珍惜设备。

页尾：**说说你的困扰。我们一起找答案。**

### 免责声明（第三页）

**每一份信任，都值得坦诚。**

免责声明与维修须知。先了解服务的边界与风险，再一起开始修复。

使用建筑光井背景，正文按服务范围、数据备份、设备风险、操作授权、隐私与外部平台、责任与异议处理六项展开。保持具体、易懂，不作一概免责或默认授权的表述。导航与页脚均提供入口。

### 旧预约兼容页

**修复此刻 / 连接更大的未来。**

不必把问题说得很专业。告诉我们发生了什么，一起找到下一步。

旧预约页保留 **开始预约 ↗** 并新增 **服务反馈 ↗**。首页和服务页使用 **预约维修 ↗** 与 **服务反馈 ↗**，预约入口均直达 `config.js` 配置的外部表单，不再经过站内预约页。没有站内预约表单。

## 字体与层级

| 用途 | 字体与处理 |
| --- | --- |
| 中文主标题 | Noto Sans SC（思源黑体同源），300 字重；大字号、紧凑字距，按语意分行 |
| 章节标题 | 同一中文字体，300 字重；比首屏缩小一级，留出更长行距 |
| 正文 | 中文 400 字重；两倍左右行距，保证深色画面上的阅读对比 |
| 导航与按钮 | 500 字重；动词明确，尺寸克制 |
| 英文品牌与标注 | Manrope；英文标签适度加宽字距，编号使用等宽数字 |

首页与服务页首屏大标题的上限为 102px，免责声明与旧预约兼容页为 78px；手机按视口缩放。长文段落保持自然换行，不用手动空格对齐。

字体在 `assets/fonts/` 本地托管，不依赖访客连接外部字体服务。随包保留字体的 OFL 文件。

## 后续编辑

中文字体仅包含当前页面及交互提示使用的字符，英文包含基本 ASCII。新增文案后，运行以下命令更新字体子集，再打包：

```sh
python3 scripts/subset_fonts.py
python3 scripts/release.py
```

字体更新脚本需要联网访问 Google Fonts 与其字体仓库；网页本身和发布打包都不需要连接这些服务。未包含的新字符会先使用系统字体回退。
