## 统一生成要求

- 三张图属于同一品牌：高端、安静、真实、克制。摄影 / 建筑可视化质量；黑色、炭灰、冷白为主，薄荷青仅为微量细节。
- 优先生成横向 **3:2，2400 × 1600 或更高**，导出 WebP，建议每张 350–900 KB。当前桌面网页使用完整场景，并由 CSS 完成与左侧文字区域的柔和衔接。
- **主体集中在画面中间 60% 区域**，重要的鸟、笔记本、光井边缘不要贴边。桌面右侧展示，手机下半屏展示，保留裁切余量。
- 上传对应效果图作为风格参考时，请告诉模型：只参考摄影主体、材质和光线，不复制文字、网页布局、导航或水印。
- 如需更精确的手机构图，可另生成 4:5 竖版，沿用对应提示词，只调整机位与留白。当前代码已提供手机专用裁切，也可用独立生成的竖版替换对应 `-mobile.webp`。

## 01 首页｜黑羽重生

**文件名：`feathers.webp`** → 覆盖项目根目录下的 `assets/images/feathers.webp`

**完整提示词：**

为一个高端志愿技术组织创作一张纯摄影式品牌主视觉，主体是一组交叠、舒展的真实黑色鸟羽微距。不是整只鸟，不是鸟标志，不是电脑或产品。羽毛由右上向左下形成有秩序的斜向构图，三至五片主羽有自然的前后层次，弧线舒展而克制。主羽集中在画面中央偏右，羽端完整，四周有充足可裁切空间。背景接近纯黑 #080A0B，左侧与边缘渐渐融入真实的黑暗，不能出现硬边。

采用 100mm 微距镜头，极其精细的羽轴、羽枝和羽小枝纹理。羽毛是真实的角蛋白质感，哑黑中有微弱石墨光泽，不能呈现塑料、金属板或磨砂橡胶质感。冷白色极细轮廓光从右上侧擦过羽毛，让黑色中仍能读出结构。少量薄荷青 #B3E7D5 光粒分布于羽毛的缝隙和远处黑暗中，只有约十余个主要光点，绝大部分非常暗，亮点面积低于画面的 1%，如同非常遥远、微弱的电子信号。粒子不能排成电路图，不能大面积发光。浅景深但主羽纹理清晰，电影级曝光，深黑层次丰富，极少细腻胶片颗粒。

视觉气质像高级时尚品牌的黑色材质特写，安静、有生命感、有力量，隐喻修复、重生和热爱的延续。横向 3:2，超高清，真实微距摄影，精确材质，克制的照明，不生成任何排版元素。

**挑图标准：** 第一眼是黑色羽毛的真实纹理，第二眼才注意到微弱青色光点。黑色背景要足够深，羽毛不能成为一团没有细节的黑影。

## 02 服务页｜技术与善意

**完整提示词：**

创作一张安静、极具电影感的建筑与自然环境摄影。一处面向辽阔山脉的现代混凝土露台，远处的山峦由近到远呈现三至四层石墨灰、蓝灰和雾灰色轮廓，天空是清晨极浅的冷灰白，地平线带极淡的奶油色自然光，只占很小比例，没有艳丽日出或金色大片。场景不需要人物。

画面下半部偏右是一道深灰色、细腻粗粝的混凝土矮墙，墙顶从左下向右上延伸，具有清晰建筑秩序和自然的细孔、风化纹理。墙上中央位置停着一只真实的小型灰黑色鸟，侧身站立，身体放松，双脚自然抓住墙沿，比例真实，羽毛细节精确。鸟旁边偏右放一台没有任何品牌标志的哑黑色薄笔记本，屏幕半开约 105 度，从侧后方观察，不显示屏幕内容。笔记本是生活中安静的物件，不是商业广告主角，不能发光，不能占据整幅画面。小鸟和笔记本之间留有呼吸空间。两者集中在画面中部区域，不要靠近最右边，以便适应手机裁切。

相机采用 50mm 镜头，视平线略低于鸟的眼睛，露台和远山形成清楚的前中后景，柔和自然漫射光，真实接触阴影，细腻的建筑摄影质感。色彩低饱和、冷白与浅灰主导，自然黑与石材灰构成稳重结构。画面像建筑事务所的文化品牌大片，有开放、连接、善意、可持续的气质，不要维修店广告感。横向 3:2，超高清摄影，整幅画面没有任何文字、Logo 或网页元素。

## 03 预约页｜走向光中

**文件名：`architecture.webp`** → 覆盖项目根目录下的 `assets/images/architecture.webp`

**完整提示词：**

创作一张具有建筑摄影真实感的深色混凝土空间。一个巨大、厚重、雕塑般的炭灰色混凝土结构形成弧形天井开口，相机位于建筑内部的阴影中，向右上方看见一个横向椭圆形、略带透视倾斜的开口。建筑不是普通门洞，也不是科幻隧道；弧形结构应该有合理的结构厚度、连续的曲面和沉静的几何秩序，如同极简当代美术馆或纪念性文化空间。

画面左侧与上方是接近 #101615 的深炭灰阴影，保留非常微妙的混凝土纹理，右侧和中部是开口带入的冷白自然光。开口内部明亮但不过曝到失去边缘，墙面由白灰过渡到深石墨灰，地面只有克制的漫反射，不要镜面地板。右上主光区占画面的约三分之一，与深色结构形成强烈但安静的明暗关系。

一只真实的小鸟正飞过开口的明亮区域，双翼自然展开，羽毛有准确结构，保持小尺度，占画面宽度的 8% 至 12%，位于中间偏上，不能遮住整个光井。可在光井底部中间偏右放一个非常小的背影人物作为尺度参照，穿黑灰色日常服装，站立望向光，人物高度不超过画面的 18%，不要看向镜头，不表现具体身份。人物是可选元素，重点始终是空间、光与飞鸟。

35mm 建筑摄影镜头，垂直线控制准确，宏大留黑，清晰的结构边缘，低饱和、自然黑、炭灰和冷白，没有彩色灯光。气质安静、庄重、有人文温度，隐喻一次修复让人与更大的未来重新连接。真实物理光照与混凝土材质，顶级建筑可视化和电影摄影质感，横向 3:2，超高清，不含任何文字、Logo、导航或界面。

文字、排版、Logo、网页、按钮、水印、科幻飞船、宇宙、赛博朋克、蓝色霓虹、发光电路、隧道光圈、门户特效、夸张体积光束、浓雾、宗教符号、废墟、恐怖、阴森监狱、拥挤人群、机器人、巨大鸟、畸形翅膀、塑料墙壁、光滑金属墙壁、大理石奢华大厅、镜面反射地面、过度曝光、低清晰度。

**挑图标准：** 先看见建筑和柔和白光，再看见飞鸟与人物。必须保留空间的压暗部分；人物只作参照，不能成为肖像。鸟的位置要在中央裁切区域内。

## 替换与校准

1. 生成后，保留高清原图在站点之外，导出上述三个同名 WebP 并覆盖项目根目录下的 `assets/images/` 中对应文件。
2. 无需修改 HTML。刷新后查看 1440px 桌面和 390px 手机视口，确认鸟、光井和笔记本未被裁出画面。
3. 新图构图如与占位图不同，在 `assets/style.css` 中调整对应 `.hero-home .hero-art`、`.hero-service .hero-art`、`.hero-architecture .hero-art` 的 `background-position` / `background-size`。手机构图在 `@media(max-width:650px)` 中单独调整。
4. 网页已用透明遮罩完成左文右图衔接，请不要在生成图里额外放文字或绘制按钮。本轮已按正式图精调遮罩位置和曝光。后续换图时请同步检查 `-mobile.webp` 与 CSS 中的资源版本号。
